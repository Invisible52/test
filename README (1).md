# Assignment 05 — Bank Account (Class-Based)

Create a Python program named `solution.py` that:

1. Accepts an initial balance as input
2. Defines a class (e.g. `BankAccount`) with:
   - a `deposit` method that adds an amount to the balance
   - a `withdraw` method that subtracts an amount from the balance
   - a way to check the current balance (e.g. a `get_balance` method or a
     `balance` attribute)
3. Creates an instance of that class using the input balance
4. Deposits **$50** and then withdraws **$20** using the class's methods
5. Displays the final balance

Example: if the input balance is `100`, the program should end by displaying
`130` (100 + 50 − 20).

Submit a single file `solution.py` inside an `assignment_05/` folder in your
GitHub repository (i.e. `assignment_05/solution.py`). Use the same repo for
every assignment this semester — just add a new folder named after each
assignment as it's assigned.
